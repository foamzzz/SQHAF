# SQHAF

This repository contains the implementation of SQHAF and the complete leave-one-subject-out (LOSO) experiments for the evaluated methods.

## Contents

- `SQHAF.py`: SQHAF implementation.
- `EEGconformer.py`, `iistlf.py`, and `SUTLSSVEP.py`: Implementations of the corresponding methods.
- `loso_experiment_0.5s.ipynb`, `loso_experiment_1.0s.ipynb`, `loso_experiment_1.5s.ipynb`, and `loso_experiment_2.0s.ipynb`: Complete LOSO experiment notebooks for the evaluated time windows.
- `metabci/`: The MetaBCI code used by the experiments.

## MetaBCI Citation
